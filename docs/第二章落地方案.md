# 第二章落地方案

这份文档用于后续继续实现第二章。目标是把第一章出门后的课堂和走廊段落落到可玩的最小闭环，再逐步补镜头、角色形象和结尾表现。

## 当前基础

已有文件：

- `scenes/gameplay/chapters/chapter2/classroom.tscn`
- `scenes/gameplay/chapters/chapter2/hallway.tscn`
- `dialogs/chapter2.dtl`
- `dialogs/ouyang_ye.dch`
- `scenes/gameplay/npc/pang.tscn`
- `scenes/gameplay/player/player.gd`

第一章玄关出口现在会在有钥匙时调用：

```gdscript
Chapter.change_scene("chapter2/classroom")
```

所以第二章入口已经接到了 `chapter2/classroom.tscn`。

## 第二章主流程

建议按这个顺序落地：

1. 玩家从第一章玄关出门，进入第二章教室。
2. 教室播放一段 Pcam 镜头：从教室前部慢慢推到教室后部。
3. 镜头结束后黑屏转场，场景或视觉状态切到走廊。
4. 进入走廊后，玩家形象切换为欧阳夜。
5. 玩家与小胖互动，播放 `chapter2/start`。
6. 对话结束后标记 `chapter2.pang_talked` 和 `chapter2.ending_seen`。
7. 进入结尾或暂时停留在走廊，等待后续章节/结局指令。

## 先做最小可玩闭环

第一步不要追求完整演出。先完成：

- `chapter2/classroom` 能稳定进入。
- 玩家能从教室门进入 `chapter2/hallway`。
- `chapter2/hallway` 里小胖可互动。
- 与小胖互动能播放 `Dialogic.start("chapter2", "start")`。
- 对话结束后玩家控制恢复。

验收方式：

```powershell
rg -n "chapter2|Pang|Dialogic.start|pang_talked|ending_seen" scenes/gameplay/chapters/chapter2 dialogs/chapter2.dtl
```

然后在 Godot 中从第一章玄关出门测试到第二章走廊。

## 处理 Dialogic 变量

`dialogs/chapter2.dtl` 当前使用：

```dtl
set {chapter2.pang_talked} = true
set {chapter2.ending_seen} = true
```

落地前要在 `project.godot` 的 `dialogic/variables` 中注册：

```gdscript
"chapter2": {
	"pang_talked": false,
	"ending_seen": false
}
```

否则会出现和第一章 `box_taken/key_taken` 类似的变量解析失败。

同时给 `chapter2/start` 末尾补 `[end_timeline]`。当前文件在解锁后没有显式结束：

```dtl
do GameManager.lock_player_control(false)
```

建议改成：

```dtl
do GameManager.lock_player_control(false)
[end_timeline]
```

## 小胖互动

`hallway.tscn` 已经有：

```text
Sortables
  Player
  Pang
```

建议给 `Pang` 添加或确认以下能力：

- 进入检测范围显示提示。
- 按互动键时播放 `Dialogic.start("chapter2", "start")`。
- 如果 `chapter2.pang_talked` 已经为 true，可以不重复播放，或播放一句短提示。

最小实现可以新建 `scenes/gameplay/chapters/chapter2/pang_interact.gd`，挂到 `Pang` 实例或 `pang.tscn`，逻辑保持简单：

```gdscript
extends Prop

func handle_interact() -> void:
	Dialogic.start("chapter2", "start")
```

如果 `pang.tscn` 不是 `Prop` 体系，则先读它的节点结构，再用最小 Area2D 互动脚本，不要强行重构 NPC 基类。

## 玩家形象切换为欧阳夜

这里采用短期方案，不做完整换装系统。

当前玩家 `SpriteFrames` 已经包含：

- 叶莉：`idle`、`move`
- 欧阳夜：`Ye_idle`、`Ye_walk`

建议在 `player.gd` 加一个小判断：

```gdscript
func _is_ouyang_ye() -> bool:
	return Chapter.cur_scene.contains("inside") or Chapter.get_data("player_is_ouyang_ye", false)
```

然后把现有 `Chapter.cur_scene.contains("inside")` 替换为 `_is_ouyang_ye()`。

进入第二章走廊前或进入走廊后设置：

```gdscript
Chapter.set_data("player_is_ouyang_ye", true)
```

建议先放在 `chapter2/hallway` 的导演脚本里：

```gdscript
func _ready() -> void:
	Chapter.set_data("player_is_ouyang_ye", true)
```

这样影响范围小，之后要做正式角色系统也容易替换。

## 教室镜头演出

`classroom.tscn` 当前已有教室背景、桌子、NPC 群组和通往走廊的门。

建议新增：

```text
CameraTargets
  IntroStart
  IntroEnd

Cameras
  IntroPanPcam

IntroFadeLayer
  Black

SceneDirector
```

实现方式参考第一章卧室和第 0 章教室：

- 进入 `chapter2/classroom` 后锁玩家控制。
- 黑场或淡入开始。
- `IntroPanPcam` 从教室前部平移到教室后部。
- 平移结束后淡黑。
- 切到 `chapter2/hallway`，可传 `player_pos`。

建议不要一开始就做复杂镜头切换。先做一台 Pcam tween `follow_offset`。

## 黑屏转场

短期建议用本场景内 `CanvasLayer/ColorRect`：

- `Black.color.a = 0.0`
- 镜头结束后 tween 到 `1.0`
- 黑屏完成后调用 `Chapter.change_scene("chapter2/hallway", 0, {"player_pos": Vector2(...)})`

后续如果项目有统一转场系统，再替换成统一的 `GGT`/全局转场。

## 第二章导演脚本建议

建议新建：

- `scenes/gameplay/chapters/chapter2/classroom_director.gd`
- `scenes/gameplay/chapters/chapter2/hallway_director.gd`

`classroom_director.gd` 负责：

- 第一次进入第二章教室的镜头演出。
- 演出期间锁玩家控制并拦截普通输入。
- 演出结束后切到走廊。
- 记录 `Chapter.set_data("chapter2_classroom_intro_played", true)`。

`hallway_director.gd` 负责：

- 设置 `player_is_ouyang_ye = true`。
- 必要时让小胖初始位置、玩家位置、镜头位置对齐。
- 如果 `chapter2.ending_seen` 已经为 true，避免重复触发核心对话。

## 推荐实施顺序

1. 注册 `chapter2` Dialogic 变量，并给 `chapter2/start` 补 `[end_timeline]`。
2. 给小胖补互动，确认能播放 `chapter2/start`。
3. 按短期方案实现玩家形象切换为欧阳夜。
4. 给 `hallway` 加导演脚本，进入后设置欧阳夜状态。
5. 给 `classroom` 加导演脚本和 Pcam 镜头。
6. 加黑屏转场，从教室镜头结束切到走廊。
7. 测试从第一章玄关出门到第二章小胖对话全流程。

## 验收清单

- 第一章玄关有钥匙出门后进入 `chapter2/classroom`。
- 教室镜头不会让玩家提前移动。
- 教室镜头结束后能进入走廊。
- 走廊里玩家显示欧阳夜动画。
- 小胖互动播放 `chapter2/start`。
- 对话结束后写入 `chapter2.pang_talked = true` 和 `chapter2.ending_seen = true`。
- 对话结束后玩家控制恢复。
- 没有 Dialogic 变量解析报错。
