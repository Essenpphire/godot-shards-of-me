- 用户希望“一步一步搭场景”：用户说一步，实现一步。
- 代码尽量简洁，只做当前要求。

- 更新代码后补中文注释。
- 不要擅自重构邻近代码，不要删除用户已有改动。

## 玩家形象变欧阳夜的短期方案

用户特别要求这里采用短期方案，不要先做完整换装/角色外观系统。

当前玩家动画资源：

- `scenes/gameplay/player/player.tscn` 使用 `assets/images/sprites/baka/baka_sprite.tres`。
- 这个 `SpriteFrames` 里已经同时有：
  - 默认叶莉动画：`idle`、`move`
  - 欧阳夜动画：`Ye_idle`、`Ye_walk`

当前 `player.gd` 的逻辑：

- 如果 `Chapter.cur_scene.contains("inside")`，播放 `Ye_idle` / `Ye_walk`。
- 否则播放 `idle` / `move`。

短期方案建议：

- 不新建全局角色外观系统。
- 直接在 `player.gd` 加一个简单判断，例如 `Chapter.get_data("player_is_ouyang_ye", false)`。
- 当这个状态为 true 时，不论场景名是否包含 `inside`，都播放 `Ye_idle` / `Ye_walk`。
- 在需要切换身份的剧情节点里，调用 `Chapter.set_data("player_is_ouyang_ye", true)`。

建议实现形态：

```gdscript
func _is_ouyang_ye() -> bool:
	return Chapter.cur_scene.contains("inside") or Chapter.get_data("player_is_ouyang_ye", false)
```

然后把现有 `Chapter.cur_scene.contains("inside")` 判断替换成 `_is_ouyang_ye()`。

这样改动小，后续如果要做正式角色系统，也容易替换。
